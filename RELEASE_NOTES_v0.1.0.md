# BioGraphBench-PPI v0.1.0

Initial reproducibility release for the BioGraphBench-PPI manuscript.

Archived DOI: https://doi.org/10.5281/zenodo.22216311

This release includes:

- acquisition, filtering, canonicalization, split-generation, validation, and reporting scripts;
- importable `biographbench` Python package components for structural features and link-prediction split logic;
- 120 PPI split manifests across four PPI datasets, three sampled-nonedge contracts, and 10 seeds;
- retained classical, node2vec-compatible, and GCN link-prediction result tables;
- statistical summaries with mean, SD, confidence intervals, calibration metrics, and runtime summaries;
- manuscript table and figure generation assets;
- `CITATION.cff`, `.zenodo.json`, `LICENSE`, and reproducibility instructions.

Raw STRING, BioGRID, and OBNB source files are not redistributed. They should be obtained from the original providers according to their respective licenses and terms.
